_Last updated: 2026-05-21_

## Schema

Each variant = one file. One job → up to 6 rows: Resume Standard (HTML+PDF) + Resume ATS-Friendly (HTML+PDF) + Cover Letter Standard (HTML+PDF). HTML = development/edit master. PDF = export/attachment. ATS-Friendly = plain-text-safe, no columns/tables/icons/styled fonts.

| Column | Values |
|---|---|
| **Document Type** | Resume · Cover Letter · Other |
| **Format** | HTML · PDF · DOCX · Markdown · Other |
| **ATS Mode** | Standard · ATS-Friendly |
| **Target Tier** | Nordic Primary · US Secondary · Speech SME · Generic · Assessment · Other |
| **Status** | Active · Drafting · Archived · Deprecated |

## Naming Convention

`{Company} {Job ID} — {Role} · {Doc Type} · {ATS Mode} · {Format}`

e.g. `Meta AI 70466-1 — Knowledge Expert Voice · Resume · Standard · HTML`

Local file names use the full Sirish Satyavolu prefix:
`Sirish Satyavolu — {Company} {Job ID} {Role} Resume.html / .pdf`

---

## Notes
- Cover letter ATS-Friendly variants: create as needed (not always required).
- ATS-Friendly resumes: plain text, single column, no icons, no tables, no custom fonts, no color blocks.
- Standard resumes: designed HTML — columns, icons, styled typography all fine.
